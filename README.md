# ☁️ CloudForge

CloudForge is a full-stack cloud file upload platform built with Node.js, Express, React, and AWS S3.

---

## 🚀 Features

- User Login & Register
- JWT Authentication
- File upload to AWS S3
- Secure backend API

---

## 🏗️ Tech Stack

- React
- Node.js
- Express
- AWS S3

---

## ⚙️ How it works

1. User logs in
2. User selects file
3. File is sent to backend
4. Backend uploads to AWS S3
5. Returns file link
